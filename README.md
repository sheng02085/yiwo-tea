## 關於

一握茶研所以臺灣佛手烏龍茶為基底，搭配不同茶材，推出「嫣然」、「輕盈」、「暖陽」三款一握系列茶飲。

網站除了介紹茶款，也提供 AI 茶伴陪你依當下心情挑一杯茶，以及「一握體驗館」讓你親手體驗製茶、調茶與茶知識問答。

## 網站功能

### AI 茶伴
說說今天的心情或壓力，AI 茶伴會陪你聊聊，並推薦一杯適合此刻的茶；推薦後會出現按鈕，直接前往該茶款頁。

### 語音對話
- **語音輸入**：AI 茶伴與茶款問答都可以按麥克風用說的，用語音問的那一題，AI 會把回答唸出來
- **語音模式**：全螢幕的語音對話，光球會跟著 AI 的聲音律動；AI 推薦茶款後會先暫停收音，並顯示前往茶款頁的按鈕
- AI 回覆一律使用繁體中文（臺灣）

### 一握體驗館
完成三個關卡、集滿三枚印章，即可領取專屬製茶證書。

1. **手勢製茶工序**：用手勢完成採摘、萎凋、浪菁、殺青、揉捻、乾燥焙火六道工序
2. **DIY 調茶**：點選玫瑰、紅棗、枸杞、陳皮、山楂、桂圓、薑加入杯中（最多 3 種），再設定水溫與浸泡時間；茶湯顏色會隨配料、水溫與時間變化
3. **茶知識問答**：測驗你對茶的認識

### 其他特色
- 品牌迎賓動畫與主視覺動畫
- 360° 拖曳旋轉茶罐
- 品牌影片
- 手機、平板、電腦響應式設計
- 支援「減少動態效果」設定

### 測試版新功能（[/test/](https://sheng02085.github.io/yiwo-tea/test/)，尚未上正式版）
- **節氣開場白**：AI 茶伴依當天日期、節氣與時段寫開場白
- **AI 幫你的茶取名**：DIY 調茶完成後由 AI 取名，可自行修改
- **證書上的「我調的茶」**：製茶證書印上你命名的那杯茶
- **跟茶伴聊這杯茶**：把調好的茶帶去 AI 茶伴繼續聊
- DIY 結果視窗精簡，配對到的茶款名稱以該茶款顏色顯示

## 技術架構

```text
前端（GitHub Pages）
   ↓
Cloudflare Worker
   ↓
Gemini API
```

- **前端**：單一 `index.html`（HTML / CSS / JavaScript、Tailwind CSS）
- **AI**：透過 Cloudflare Worker 串接 Google Gemini API（對話與語音朗讀）
- **語音**：辨識用瀏覽器內建的 Web Speech API；朗讀以 Gemini 聲音為主，連不上時改用手機內建聲音
- **影片**：Cloudflare R2 + Worker
- **流量分析**：Cloudflare Web Analytics（不使用 cookie）
- **部署**：GitHub Pages
